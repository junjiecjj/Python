# Reweighted ADMM-Based Robust DOA Estimation for Multiple Ships Using VSA

## Project Overview

This project presents a robust Direction of Arrival (DOA) estimation method for multiple underwater acoustic sources using a Circular Vector Sensor Array (VSA). The proposed approach formulates the DOA estimation problem as a sparse recovery problem and solves it using a Reweighted Alternating Direction Method of Multipliers (R-ADMM).

The system is designed to improve DOA estimation accuracy under challenging underwater conditions such as coherent interference, non-coherent interference, impulsive noise, and sensor Non-Orthogonal Deviation (NOD).

---

## Objectives

- Estimate the Direction of Arrival (DOA) of multiple underwater acoustic sources.
- Improve estimation accuracy using Reweighted ADMM.
- Handle coherent and non-coherent interference.
- Model Non-Orthogonal Deviation (NOD) in Vector Sensor Arrays.
- Compare the proposed method with the MUSIC algorithm.
